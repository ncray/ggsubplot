## Synthetic datasets in this version

The current data/nasa.rda and data/casualties.rda are entirely synthetic,
independently generated by tools/generate-synthetic-data.R on 2026-10-03.
The generator reads no original data and uses deterministic formulas, not fitted
parameters from the historical records. These new example datasets are
GPL-2.0-or-later, like the fork code. They do not describe real observations,
people, casualties, or events. Names and column conventions preserve historical
example compatibility; numerical values and row counts have changed.

All bundled data-derived galleries and visual snapshots were regenerated from
these replacements. Their plot titles explicitly identify synthetic data.

## Historical dataset provenance

Earlier upstream/local Git objects contain third-party data: `nasa` from the
2006 American Statistical Association Data Expo (NASA Langley ASDC), and
`casualties`, lightly cleaned from the Afghan War Diary distributed by WikiLeaks.
These original records are not included in the current source distribution.
This fork does not claim ownership or grant new permissions for those records.
Historical sources, retained for attribution:

* https://community.amstat.org/stat-computing/data-expo/data-expo-2006
* http://www.wikileaks.org/wiki/Afghan_War_Diary,_2004-2010

The existing local Git history is preserved for traceability, but should not be
pushed as the public repository while those historical dataset rights remain
unresolved. Use tools/prepare-public-source.py to make a current-source export
without Git objects or local development artifacts, then initialize a new public
repository from that export. It retains this attribution and upstream baseline
identifier; it intentionally does not redistribute the historical datasets.
Original contribution history is available in the upstream repository:
https://github.com/garrettgman/ggsubplot/graphs/contributors
